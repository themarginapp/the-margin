# Getting help

- **How do I...?** Start with the [docs](https://themarginapp.com/docs), then ask in [Discussions](https://github.com/themarginapp/the-margin/discussions).
- **Something is broken:** open a [bug report](https://github.com/themarginapp/the-margin/issues/new/choose).
- **Account, billing or anything private:** email [hello@themarginapp.com](mailto:hello@themarginapp.com).
- **Is it down?** Check [themarginapp.com/status](https://themarginapp.com/status).
