# Contributing

Thank you for wanting to help. The Margin's application code is not open source, so the most useful contributions are these:

- **Bug reports** with the steps that led to the problem, what you expected and what happened.
- **Feature requests** that describe the problem you are trying to solve, more than the solution.
- **Fixes to this repository:** a client config that changed, a clearer example, a typo. Open a pull request.

Before opening an issue, search for an existing one and add to it if you find it. Keep personal details, tokens and screenshots of private data out of anything you post here.

Everyone taking part is expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
