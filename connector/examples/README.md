# Examples

## Configs

- [`mcp.json`](mcp.json): for clients that support OAuth. Cursor reads this from `.cursor/mcp.json`.
- [`mcp-with-token.json`](mcp-with-token.json): for scripts and clients that cannot open a browser. Make the token in Settings → Integrations and keep it out of version control.
